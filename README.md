# infillGLS

This repository contains two standalone components for infill generalized
least squares:

- [`lib/infillgls`](lib/infillgls/): an R package for spatial GLS estimation
  with user-specified covariance kernels.
- [`lib/InfillGLSLean`](lib/InfillGLSLean/): a Lean/Mathlib formalization of
  the associated asymptotic results.

See the README in each component for installation, build, and API details.

Maintained by Christopher Engh.
